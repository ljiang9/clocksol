# clocksol - 时钟纸牌

终端里的 Clock Solitaire（时钟单人纸牌）。**纯运气游戏，没有任何决策点**——发完牌结局就定了，看牌自己翻完。

## 玩法

13 堆牌摆成钟面：A=1 点位 … Q=12 点位，K=中央。每堆 4 张，牌背朝上。

1. 从中央堆翻开顶牌；
2. 按点数把它放到对应牌堆下面（比如翻到 7 就放到 7 点位堆底），再翻开该堆的顶牌；
3. 重复。翻出第 4 张 K 时如果还有牌没翻完 → 失败；52 张全翻完 → 胜利。

## 用法

```bash
python -m clocksol              # 玩一局（自动翻牌，看结果）
python -m clocksol -v           # 打印每一步翻牌过程
python -m clocksol --auto 1000  # 模拟 1000 局，统计胜率
python -m clocksol --auto 1000 --seed 1
```

## 设计取舍

- 交互就是"看"：规则本身没有分支选择，所以不做假装能操作的界面，`-v` 看过程即可。
- 胜率约 1/13（≈7.7%）：第 4 张 K 出现在第几张决定一切，数学上就是 K 的分布问题。

## 已知局限

- 几乎纯运气，玩多了会腻——这是规则本身决定的，不是 bug。
- 无动画、无存档、无排行榜。
